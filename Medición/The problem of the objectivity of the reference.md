“In communication, not every individual object in the world is differentiated and named. Instead, through observation and a process of abstraction called conceptualization, objects are categorized into classes, which correspond to units of knowledge called concepts, which are represented in various forms of communication.”

  

The text seems extremely interesting to me, among other things because it differentiates the scientific from the nonscientific by its ability to think concepts, which it calls units of knowledge. This "unit" does not necessarily refer to number 1, but I understand that it is much closer to it than "every individual object in the world"

  

This triggers a question that has also arisen in several of your papers on qualitative quantities, weak measurement, or social science measurement, and I will use this text to formulate it.

  

In section 1 you explain the view of J. C. Maxwell and get the following formulas:

  

1. Q = {Q}[Q]
    

where Q is the quantity to be expressed, {Q} is a number and [Q] is a measurement unit. This is now a standard expression within the so called quantity calculus. If written:

2. {Q} = Q/[Q]
    

this expression justifies why entities such as Q are called “ratio quantities”.

  

If it is possible to get formula 2 from formula 1 it is because the expression  {Q}[Q] must be understood as {Q}*[Q]. And, consequently, that [Q] is a shortened expression of 1[Q]. 

So again:

Q = {Q}* 1[Q]

And

{Q} = Q/1[Q]

  

Then, by using your first example: “the length of this object is 1.23 m”, we repeat the formula:

Length = 1.23* 1m

And

Length / 1 m = 1.23

  

The last one can be read as "the length, with respect to 1m (the reference unit), is 1.23”.

  

This seems to apply only to rate quantities, while for cases like the second example:

The shape of this object is E3 in a given classification system

  

you proposed a general expression P = {P}[P], where the term {P}[P] has to be read “{P} in reference to [P]”, not “{P} times [P]”. In such case, a derivation like {P} = P/[P] is not available.

  

But does this mean that if we have a nominal or an ordinal quantity there is not such a “reference unit”, but just a “reference”? The unity character of the reference, in the sense of unit of knowledge, although it does not have to do with the number 1, is not a condition for the scientific character of the expression, as it stated by the ISO 704 standard? In this sense, what is supposed to be the unit in “a given classification system” in the example?

  

In short, what must be the conditions for the definition of the reference, when it is not directly a mathematical unit, so that it can be considered a concept in the sense of the ISO 704 standard? Note this question is associated to the one in the previous item, and that can be named “the problem of the objectivity of the reference”.

  

You will know how to evaluate if these considerations deserve attention, and whether it is possible to continue deepening them in a more detailed study.
