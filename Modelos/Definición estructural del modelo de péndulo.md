#error_categorial 

[[Definición de martillo]]

Ahora bien, pretender un paralelo con el modelo científico y buscar una definición estructural para éste similar a como se lo hizo con el martillo es un error categorial. "Modelo científico" es un genérico, y un paralelo requeriría cotejarlo con algo así como "Instrumento técnico o tecnológico" en lugar de con "martillo". El ejemplo del martillo entonces permite aspirar a la estructura no del modelo científico en general, sino de un modelo dado, por ejemplo el del péndulo. Pero tampoco se trata de encontrar la estructura de un modelo de péndulo individual, sino la del modelo de péndulo en términos generales: por ejemplo que consiste en un soporte fijo, un elemento que sirve de unión entre el soporte y una masa, y la masa que se mueve de manera periódica. Todos conocemos las características de las relaciones entre estos elementos y las propiedades particulares que éstos deben tener según estas relaciones. Los elementos forman el patrón del péndulo y han de aplicarse tanto a cualquier modelo de péndulo que se precie como tal, como a cualquier sistema empírico que sea identificable como un péndulo según estos modelos.
